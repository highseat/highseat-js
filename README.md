# highseat-js

The source of the [`highseat`](https://www.npmjs.com/package/highseat) npm package: typed tracking, a first-party proxy and framework components for [Highseat](https://highseat.com) analytics.

**This repository is a read-only mirror.** The package is developed in Highseat's private monorepo, and every commit here is a one-way sync from it. Pull requests and edits made here are overwritten by the next sync, so this repository takes no issues or pull requests.

- Package documentation: [`packages/highseat`](packages/highseat)
- Report a problem: [support@highseat.com](mailto:support@highseat.com)

## Releases

Each version is published to npm from this repository's GitHub Actions with [npm trusted publishing](https://docs.npmjs.com/trusted-publishers), so every release carries a [provenance attestation](https://docs.npmjs.com/generating-provenance-statements) that links it to the commit and the workflow run that built it.
